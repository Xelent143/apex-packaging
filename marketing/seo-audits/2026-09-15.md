## Applied fixes

### Dependency lockfile repair

`package-lock.json` omitted optional packages needed for a reproducible clean installation, including esbuild, Rollup and sharp platform packages. Regenerated missing entries with npm and confirmed a clean install succeeds. Existing locked package versions are unchanged.

### Organization service catalog schema

Changed `makesOffer: { @type: OfferCatalog }` to `hasOfferCatalog: { @type: OfferCatalog }` in `src/lib/schema.ts`. The nested Offer and Service entries are retained. [Schema.org hasOfferCatalog](https://schema.org/hasOfferCatalog) accepts OfferCatalog; [makesOffer](https://schema.org/makesOffer) expects Offer. The shared layout distributes the correction to generated pages. Live checks precede this commit/deployment; deployment of the corrected schema is not claimed.

## Open issues and recommended fixes

### P1 — Daily generator republishes existing article content

The generator selects `topics[dayNumber % topics.length]` and creates date-suffixed URLs. There are 30 duplicate title groups covering 64 routes, with 30 duplicate description groups. Example: the August 10 and September 9 moving/storage articles have identical BaseLayout markup after date normalization (SHA-256 `f899b6e5dc802e7c7b4db4d14a7878aa111d8184d07d1f9ba40e427c16f3c186`). Recent blogs also use long repeated titles and descriptions; changing only metadata would not resolve duplicate article content.

Recommended follow-up: use Search Console traffic/indexing data to choose the retained URL for each topic, consolidate repetitions with redirects, and change the publishing workflow to require a new substantive angle or update the retained article. These changes alter existing published URLs and the daily publishing workflow, so this audit leaves them for editorial review.
