## LinkedIn post

3 box sizes. 3 artwork files. One combined quantity can leave a supplier guessing.

For a wholesale packaging reorder, give each SKU its own line: dimensions, packed weight, material, print version, quantity and required delivery date. Identify the parcel or pallet route and any changes since the approved sample.

Then compare quotes on the same basis. Are tooling, samples and freight included? Does the minimum order quantity apply to each size or print version? Have the board grade and print coverage stayed the same?

Keep the approved sample and specification record together so the next order has a clear reference.
