## LinkedIn post

1 merchandise bundle can have 2 different shipping jobs: a parcel sent to a customer and a case sent to an event team.

For a Nashville merchandise program, start with the full bundle. Measure the folded garment size range, list the keepsake and printed pieces, and share the packed weight. A sample should let you check fit, item movement, closure and the packing sequence.

Then define the destination. Does the event team need assembled kits or flat packaging? How many bundles go in each outer carton? Who can receive the shipment, during which dates, and with what unloading access?
